About Memory Lane

Memory Lane is a free online recognition game for adults living with early-stage dementia or mild memory changes. Each of the five rounds shows one plain question and three large pictures of everyday objects — a kettle, a scarf, a clock — and asks which one fits. Because the answer is always visible on screen, the game leans on recognising something familiar rather than recalling it from nothing, which tends to feel easier and more pleasant. There is no timer, no score, and no wrong-answer buzzer: an unexpected choice simply names the intended answer and moves on. A full game takes about five minutes, and you can stop after any round.
