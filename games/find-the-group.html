About Find the Group

Find the Group is a free online categorisation game for adults living with early-stage dementia or mild memory changes. Each of the five rounds lays out five pictures and names an everyday category — fruits, ways to travel, kitchen items, clothing, garden things — then asks you to tap the three that belong. These are broad, long-familiar groupings, so the task usually feels like ordinary sorting rather than a test. Nothing is timed, and you tap "Check my answer" only when you feel ready. If some picks differ, the game names the full group warmly and carries on. A full game takes about five to ten minutes.
